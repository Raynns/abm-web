# ABM Web Address Management Part 2

Folder ini disiapkan untuk dataset wilayah Indonesia.

File yang digunakan:
- provinces.json
- regencies.json
- districts.json
- villages.json

Format:
- provinces: id, code, name
- regencies: id, province_id, code, name
- districts: id, regency_id, code, name
- villages: id, district_id, code, name

Dataset lengkap wilayah Indonesia dapat ditempatkan pada folder ini.
